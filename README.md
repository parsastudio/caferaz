# سیستم جامع مدیریت و فروش سفارشی‌سازی‌شده قهوه «کافه راز»

پروژه **کافه راز** یک وب‌سایت تجارت الکترونیک تخصصی برای شخصی‌سازی، فرآوری و فروش عمده و خرده قهوه فله است. این سیستم با بهره‌گیری از معماری مدرن **Next.js 16 (App Router)**، **React 19** و **Prisma ORM** طراحی و پیاده‌سازی شده است. تمرکز اصلی پروژه بر ارائه یک تجربه کاربری پویا، فرآیندهای بهینه‌شده سمت سرور و یک پنل مدیریت همه‌جانبه برای کنترل تمامی ارکان فروشگاه است.

## 🚀 ویژگی‌های کلیدی پروژه

### بخش مشتریان (Client-Side)
*   **سیستم شخصی‌سازی نسبت دانه‌ها (Blend Selector):** امکان انتخاب نسبت‌های مختلف دانه عربیکا و روبوستا به همراه شبیه‌ساز پویای ویژگی‌های طعمی (میزان کافئین، بادی/غلظت، اسیدیته و رایحه) با انیمیشن‌های روان Framer Motion.
*   **وزن‌دهی منعطف (Weight Selector):** پشتیبانی از وزن‌های پیش‌فرض بسته‌بندی (۲۵۰ گرم تا ۵ کیلوگرم) در کنار بخش انتخاب وزن دلخواه با اعتبارسنجی خودکار.
*   **محاسبه‌گر پویای قیمت نهایی:** اعمال آنی قیمت بر اساس نرخ روز هر کیلوگرم عربیکا و روبوستا، وزن انتخابی، تعداد بسته‌ها و کدهای تخفیف فعال.
*   **فرآیند تسویه حساب مرحله‌ای (Multi-step Checkout):** ثبت آدرس و مشخصات، اعمال کد تخفیف با اعتبارسنجی زمان واقعی، و تایید نهایی شماره تماس از طریق پیامک.
*   **کدهای تخفیف هوشمند:** امکان تعریف کوپن‌های درصدی یا ثابت، با قابلیت بررسی سقف تخفیف، بررسی تاریخ انقضای شمسی و میلادی، حداقل وزن مورد نیاز، و کنترل همپوشانی (Stacking) با سایر تخفیف‌های سیستم.
*   **بخش نظرات تعاملی با Optimistic UI:** کاربران می‌توانند دیدگاه‌ها و امتیازهای خود را ثبت کنند؛ این نظرات با استفاده از قابلیت Optimistic Updates بلافاصله به کاربر نمایش داده می‌شوند تا حس سرعت بهتری منتقل شود، در حالی که فرآیند ذخیره‌سازی در پس‌زمینه سمت سرور انجام می‌پذیرد.
*   **پنل پیشخوان کاربر (Profile Dashboard):** رهگیری آنلاین وضعیت سفارش جاری، مشاهده تاریخچه دقیق فاکتورهای قبلی و ذخیره‌سازی خودکار اطلاعات آدرس و تماس برای خریدهای بعدی.

### بخش مدیریت (Admin-Side)
*   **داشبورد آمار حیاتی:** نمایش زنده درآمد کل، تعداد کل سفارش‌ها، سفارش‌های در جریان و منتظر بررسی، دیدگاه‌های معلق، و وضعیت حجمی موجودی انبار.
*   **مدیریت هوشمند سفارش‌ها:** امکان فیلتر سفارش‌ها بر اساس وضعیت (بررسی‌نشده، در حال انجام، تکمیل‌شده، لغو شده)، تغییر وضعیت سفارش‌ها و حذف آن‌ها.
*   **کنترل نرخ‌های پایه و موجودی (Pricing & Stock Control):** امکان به‌روزرسانی آنی قیمت هر کیلوگرم دانه عربیکا، روبوستا و موجودی کل انبار بر اساس کیلوگرم.
*   **موتور تعریف کوپن تخفیف:** تعریف سه مدل تخفیف: ۱. تخفیف مستقیم و خط‌خورده روی کالا ۲. تخفیف شرطی (مثلاً خرید بالای ۵ کیلوگرم) ۳. کدهای دستی قابل استفاده توسط مشتریان در سبد خرید.
*   **مدیریت پیشرفته نظرات:** امکان تایید، رد، ویرایش مستقیم متن نظرات و ثبت پاسخ‌های تو در تو (Nested Replies) به عنوان پشتیبان سایت.
*   **مدیریت محتوای داینامیک (Settings & FAQ):** ویرایش متون لندینگ، اطلاعات ارتباطی فوتر (تلفن‌ها، شبکه‌های اجتماعی) و مدیریت پویای سوالات متداول (FAQ) با قابلیت افزودن، ویرایش و حذف مستقیم از پنل مدیریت.

## 🛠️ ساختار فنی و تکنولوژی‌های استفاده‌شده

*   **فریم‌ورک:** Next.js 16.2 (با ساختار App Router و React Server Components) به همراه React 19.
*   **مدیریت پایگاه داده و ORM:** استفاده از PostgreSQL به همراه Prisma Client و اتصال بهینه‌شده به کمک `@prisma/adapter-pg` برای مدیریت کارآمد کانکشن‌پول‌ها در محیط‌های Serverless/Edge.
*   **اعتبارسنجی داده‌ها:** استفاده از کتابخانه Zod برای ساخت شِماهای اعتبارسنجی ورودی‌ها در لایه کلاینت و سرور.
*   **فرم‌ها:** React Hook Form به همراه `@hookform/resolvers/zod`.
*   **طراحی رابط کاربری و استایل:** Tailwind CSS v4، کامپوننت‌های Radix UI (در قالب معماری منعطف Shadcn UI با سبک تصویری Radix Nova).
*   **انیمیشن‌ها:** Framer Motion جهت انتقال‌های نرم بین بخش‌ها و فرم‌ها.
*   **اعلام وضعیت (Notifications):** Sonner جهت نمایش نوتیفیکیشن‌های تعاملی و زیبا.
*   **سیستم تاریخ جلالی:** پیاده‌سازی توابع تبدیل تاریخ بومی در فایل `src/lib/jalali-converter.ts` برای مدیریت دقیق بازه‌های زمانی کدهای تخفیف بر اساس تقویم شمسی.

## 🔒 معماری امنیت و نشست‌ها (Sessions & Auth)

پروژه به جای استفاده از پکیج‌های سنگین خارجی، از یک پیاده‌سازی بومی، سبک و ایمن استفاده می‌کند:
1.  **توکن‌های امضا شده مستقل (Custom Signed Tokens):** در فایل `src/lib/session.ts` با استفاده از الگوریتم رمزنگاری `SHA-256 HMAC` توکن‌های نشست برای مدیران و کاربران تولید می‌شوند. این توکن‌ها شامل شناسه کاربر و زمان انقضای رمزنگاری‌شده هستند که از دستکاری کوکی‌ها توسط کلاینت جلوگیری می‌کند. فرآیند تطبیق امضاها با استفاده از تابع ایمن زمان ثابت `crypto.timingSafeEqual` برای پیشگیری از حملات زمان‌بندی (Timing Attacks) انجام می‌شود.
2.  **سیستم یکبار مصرف OTP ایمن:** ثبت سفارش و ورود کاربران با استفاده از کد پیامکی صورت می‌گیرد. این بخش با رویکرد ضد Brute-Force توسعه یافته است:
    *   محدودیت تعداد ارسال کد بر اساس IP (حداکثر ۱۰ بار در ساعت) جهت جلوگیری از حملات محروم‌سازی از سرویس (DoS).
    *   محدودیت تعداد ارسال بر اساس شماره تماس (حداکثر ۵ بار در ساعت).
    *   فاصله زمانی اجباری ۱۲۰ ثانیه‌ای بین درخواست‌های مجدد ارسال کد.
    *   سقف تلاش مجاز برای حدس زدن کد تایید (حداکثر ۵ تلاش)، که در صورت تخطی، کد بلافاصله باطل می‌شود.

## 📊 مدل‌های داده و ساختار دیتابیس (Schema)

دیتابیس در بستر PostgreSQL و بر اساس یک طراحی رابطه‌ای نرمال‌سازی شده پیاده‌سازی گردیده است:

```prisma
// خلاصه ساختار جداول اصلی در prisma/schema.prisma

model Product {
  id          String      @id @default(cuid())
  name        String
  description String
  stockGrams  Int         @map("stock_grams")
  isActive    Boolean     @default(true) @map("is_active")
  pricing     Pricing?
  comments    Comment[]
  orderItems  OrderItem[]
  coupons     Coupon[]
}

model Pricing {
  id                String  @id @default(cuid())
  productId         String  @unique @map("product_id")
  product           Product @relation(fields: [productId], references: [id], onDelete: Cascade)
  pricePerKgArabica  Int     @map("price_per_kg_arabica")
  pricePerKgRobusta Int     @map("price_per_kg_robusta")
}

model Order {
  id              String      @id @default(cuid())
  userId          String?     @map("user_id")
  user            User?       @relation(fields: [userId], references: [id], onDelete: SetNull)
  couponId        String?     @map("coupon_id")
  coupon          Coupon?     @relation(fields: [couponId], references: [id], onDelete: SetNull)
  finalPrice      Int         @map("final_price")
  customerName    String      @map("customer_name")
  customerPhone   String      @map("customer_phone")
  customerAddress String      @map("customer_address")
  status          OrderStatus @default(unreviewed)
  orderItems      OrderItem[]
}

model OrderItem {
  id          String   @id @default(cuid())
  orderId     String   @map("order_id")
  order       Order    @relation(fields: [orderId], references: [id], onDelete: Cascade)
  productId   String   @map("product_id")
  product     Product  @relation(fields: [productId], references: [id], onDelete: Restrict)
  weightGrams Int      @map("weight_grams")
  quantity    Int
  grindType   String   @map("grind_type")
  price       Int      // ذخیره قیمت نهایی در زمان خرید برای آرشیو مالی صحیح
}

model User {
  id        String    @id @default(cuid())
  name      String
  phone     String    @unique
  address   String?
  orders    Order[]
  comments  Comment[]
}

model Coupon {
  id                String        @id @default(cuid())
  code              String        @unique
  type              CouponType
  discountType      DiscountType
  discountValue     Int
  productId         String?
  minWeightGrams    Int?
  validFrom         DateTime?
  validTo           DateTime?
  maxDiscountAmount Int?
  isActive          Boolean       @default(true)
  allowStacking     Boolean       @default(false)
}
```

## 🛠️ راهنمای راه‌اندازی و اجرای محلی پروژه

### پیش‌نیازها
*   نصب بودن **Node.js** (نسخه ۱۸ یا بالاتر پیشنهاد می‌شود)
*   دسترسی به پایگاه داده **PostgreSQL**

### مراحل نصب

۱. ابتدا مخزن پروژه را شبیه‌سازی کرده و وارد پوشه آن شوید:
```bash
git clone <repository-url>
cd coffee-shop
```

۲. بسته‌های وابستگی (Dependencies) پروژه را نصب کنید:
```bash
npm install
```

۳. یک فایل با نام `.env` در مسیر اصلی پروژه بسازید و متغیرهای محیطی زیر را در آن مقداردهی کنید:
```env
DATABASE_URL="postgresql://USERNAME:PASSWORD@localhost:5432/DATABASE_NAME?schema=public"
SESSION_SECRET="یک_رشته_تصادفی_و_امن_حداقل_۳۲_کاراکتری"
```

۴. ساختار دیتابیس را بر روی پایگاه داده خود اعمال (Migrate) کنید:
```bash
npx prisma db push
```

۵. اسکریپت Seed دیتابیس را برای ایجاد داده‌های پایه (محصول اصلی قهوه، تنظیمات پیش‌فرض، کاربران و متون سایت) اجرا کنید:
```bash
npx prisma db seed
```

۶. پروژه را در محیط توسعه راه‌اندازی کنید:
```bash
npm run dev
```

وب‌سایت اکنون در آدرس `http://localhost:3000` در دسترس است. 
*   برای ورود به پنل مدیریت می‌توانید به آدرس `http://localhost:3000/admin` بروید.
*   نام کاربری ادمین به صورت پیش‌فرض `admin` بوده و رمز عبور پیش‌فرض آن در فایل seed مشخص شده است (که می‌توانید آن را از طریق بخش "تغییر رمز عبور" در خود پنل ادمین تغییر دهید).

## 📂 ساختار پوشه‌بندی کلیدی پروژه

*   `src/actions/`: شامل توابع **Server Actions** در Next.js برای مدیریت مستقل منطق کسب‌وکار بدون نیاز به نوشتن API Routeهای سنتی (مانند فرآیندهای خرید، ثبت کامنت، تایید کوپن و احراز هویت ادمین/کاربر).
*   `src/app/`: سیستم مسیریابی مبتنی بر فایل (App Router) شامل صفحات کلاینت، ادمین، پروفایل و صفحات ورود.
*   `src/components/features/`: کامپوننت‌های اختصاصی و تفکیک‌شده کلاینت و سرور که بر اساس ویژگی‌ها (سبد خرید، لندینگ، فرآیند تسویه حساب، مدیریت ادمین) دسته‌بندی شده‌اند.
*   `src/context/`: شامل контекست‌های کلاینت (مانند مدیریت وضعیت باز/بسته بودن فرم خرید).
*   `src/hooks/`: هوک‌های سفارشی کلاینت برای جداسازی منطق پویای فرم‌ها از ساختار نمایشی کامپوننت‌ها (مانند مدیریت فرم سفارش، فرم دیدگاه و فرآیندهای محاسباتی مربوطه).
*   `src/lib/`: کتابخانه‌ها و توابع کمکی مشترک مانند پیکربندی Prisma Client، توابع محاسباتی مالی و شخصی‌سازی قهوه، سیستم تبدیل تاریخ جلالی و سیستم مدیریت توکن‌های امنیتی.
